SET UP ONCE (BY THE OWNER)

- Enable APIs: compute, storage, iamcredentials
- Create service accounts at-control and at-worker (no keys)
- Create one private bucket; give both accounts Storage Object Admin
  on that bucket only
- Create role atWorkerOperator; bind it to at-control on the L4 VM only
- Attach at-worker (cloud-platform scope) to the L4 VM
- Create the control VM (e2-micro) in the same zone and VPC, running
  as at-control
- Firewall: tcp:8000 from at-worker to at-control; SSH from
  35.235.240.0/20 only
- Allow an external IP on the control VM
- Set a budget alert
- Confirm the L4 is not used by anyone else (it is stopped automatically
  when idle)
